## 1. 完整规则

### 1.1 资产池

```
DEFENSE_POOL = [沪深300(510300), 创业板(159915), 纳指(513100), 黄金(518880), 国债ETF(511010)]
REPO        = 逆回购 GC001 (年化 2%)
```

趋势过滤为负的 ETF 被剔除出 active 池。全部为负 → 全仓逆回购。

### 1.2 初始权重规则

active ETF 等权分配：`weight_i = 1 / N_active`

### 1.3 仓位乘数公式（50/50 A/B）

```
if circuit_breaker_triggered:
    final_multiplier = 0.0         # 全部清仓
else:
    A = drawdown_multiplier        # 纯A端：无波动率缩放
    B = min(scaling_factor, A)     # 纯B端：波动率缩放截断
    final_multiplier = (A + B) / 2 # 50/50 组合
```

防御池 = total_capital × defense_ratio × final_multiplier
进攻池 = total_capital × (1 - defense_ratio) × final_multiplier
defense_ratio = 1.00（进攻层搁置，进攻池 = 0 → 进逆回购）

### 1.4 波动率缩放公式

```
returns    = log(prices / prices.shift(1)).dropna()
w_t        = (1 - λ) * λ^(T-t) / sum(weights)   # EWMA λ=0.94
cov_matrix = 252 * sum(w_t * centered[t, i] * centered[t, j])
pred_vol   = sqrt(w^T * cov * w)

scaling_factor = target_vol / pred_vol            # 如果超出容忍带
scaling_factor = 1.0                              # 如果 |pred_vol - target| ≤ tolerance
```

目标波动率 0.15, 容忍带 0.0225 (≈ 0.15×15%)。sf 仅缩仓不加仓：`min(sf, dd_mult)` 截断。

### 1.5 趋势过滤

```
annualized_return     = ln(P_t / P_{t-N}) * (252 / N)          # N=40
annualized_volatility = std(log_returns, ddof=1) * sqrt(252)
trend_strength        = annualized_return / annualized_volatility
active                = trend_strength > 0
```

### 1.6 回撤控制

```
drawdown = (NAV - running_max_NAV) / running_max_NAV

| abs(dd) < 8%         → multiplier = 1.0  (normal)
| 8% ≤ abs(dd) < 12%  → multiplier = 1.0  (warning, 仅告警)
| 12% ≤ abs(dd) < 18% → multiplier = 0.5  (halve)
| abs(dd) ≥ 18%        → multiplier = 0.0  (liquidate)
```

清盘恢复机制：逆回购利息让 NAV 微涨，drawdown 回到 -12% 以上时自动恢复 halve(0.5)。

### 1.7 股债相关性熔断

```
stock_basket = equal_weight(沪深300, 创业板, 纳指)   # 日 log 收益等权
bond_rets    = log(国债ETF / 国债ETF.shift(1))
roll_corr    = rolling_corr(60, stock_basket, bond_rets)   # 60日滚动Pearson
smoothed     = SMA(5, roll_corr)                            # 5日SMA平滑
triggered    = smoothed > 0.0                                # 正相关→熔断
```

熔断触发 → final_multiplier = 0 → 全部资金进逆回购。

## 2. 每日决策流程

```
每日收盘后:

1. 读取收盘价 → prices[name]["close"]

2. 趋势过滤:
   for each ETF:
       trend_strength = annualized_return(40d) / annualized_volatility(40d)
   active = [ETF for ETF in pool if trend_strength > 0]

3. 等权分配:
   weight = 1.0 / len(active)

4. 波动率缩放:
   cov = ewma_covariance(active_close, lambda=0.94, window=252)
   pred_vol = sqrt(weight^T * cov * weight)
   sf = target_vol / pred_vol if |pred_vol - target| > tolerance else 1.0

5. 相关性熔断:
   stock_ret = mean(沪深300, 创业板, 纳指 log_returns)
   bond_ret  = 国债ETF log_returns
   smoothed_corr = SMA(5, rolling_corr(60, stock_ret, bond_ret))
   cb_triggered = smoothed_corr > 0.0

6. 回撤止损:
   drawdown = (NAV - max(NAV_history)) / max(NAV_history)
   multiplier = 1.0 | 0.5 | 0.0 (按 drawdown 区间)

7. 合并乘数:
   if cb_triggered: final_mult = 0.0
   else: final_mult = (dd_mult + min(sf, dd_mult)) / 2

8. 资金路由:
   defense_pool = total * final_mult
   分配 defense_pool * weight_i 到每只 active ETF
   剩余 → 逆回购

9. 执行 (次日):
   买入: exec_price = close * (1 + slippage_bps/10000)
   卖出: exec_price = close * (1 - slippage_bps/10000)
   佣金: abs(target - current) * commission_rate
   逆回购日息: repo_cash *= (1 + 0.02/252)
```

- 不含 sf：~ -2.5 Sharpe（涨跌停 + T+1 延迟 + 18% 止损封底）

### 6.6 熔断鲁棒性评估 (T+1)

**阈值 0.0 在 T+1 下依然稳健。** 三维扫描总结：

1. **corr_threshold**: 0.0 在最优位。Sharpe 在 -0.05/0.00/0.05 均为 1.06。>0.05 方向危险——回撤跳至 -17.9%（逼近 liquidate 18% 线）。T+1 下 -0.05 阈值的 ΔSharpe 退化最严重（-0.16），因高触发率（34.4%）加剧 1 日延迟的假熔断效应

**结论**：熔断三参数在 T+1 下没有悬崖式退化。当前默认值 (0.0, 60, 5) 在 T+1 下仍为稳健（回撤控制最优）。唯一注意——threshold 不要正向偏离（>0.05 危险），corr_window 不要过短（<40 危险）。

### 6.8 股债相关性经济驱动力分解

> 2026-06-18 | 脚本 `scripts/macro_corr_decomposition.py` | 数据: `data/macro_indicators.parquet`

**问题**：smoothed_corr 的变动能否用宏观经济变量解释？如果能，则可用宏观数据做熔断预警。

**因子**：CN 10Y 收益率、10Y-2Y 利差、CPI 同比（月频→日频填充）、US-CN 利差（美10Y - 中10Y）。

**样本**：2747 个共同交易日，覆盖 2013-11 ~ 2026-06。

#### 全期 OLS 回归

| 因子 | beta | SE | t | p | 贡献 (\|beta\| × std) |
|------|------|------|------|------|------|
| const | -0.6379 | 0.0226 | -28.18 | <0.001 | — |
| CN 10Y | +0.1962 | 0.0071 | +27.51 | <0.001 | **0.1244** |
| 10Y-2Y Spread | -0.1431 | 0.0159 | -8.99 | <0.001 | 0.0276 |
| CPI YoY | -0.0143 | 0.0064 | -2.22 | 0.0265 | 0.0068 |
| US-CN Spread | +0.0192 | 0.0032 | +6.08 | <0.001 | 0.0275 |

**R² = 0.319, adj R² = 0.318**。宏观因子能解释 ~32% 的 smoothed_corr 变动。

#### 因子解读

1. **CN 10Y 主导**（贡献 0.1244，是第二名 4.5 倍）。中国 10 年国债收益率越高，股债相关性越正。解释：高利率环境压制股市估值，债市同步承压（债券价格下跌 ≠ 负相关）。利率上行周期股债价格同跌 → 相关性转正。
2. **10Y-2Y 利差扩大 → 相关性更负**（beta = -0.1431）。利差扩大通常发生在宽松周期（短端下得快），此时股市受益于流动性宽松而债市平稳，相关性趋负。反之利差收窄甚至倒挂预示衰退担忧，股债同跌。
3. **US-CN 利差扩大 → 相关性更正**（beta = +0.0192）。中美利差扩大 = 美国加息快于中国 / 中国降息快于美国，资本外流压力压制 A 股，同时国内宽松压低中债收益率 → 股跌债涨被两者同向压制。
4. **CPI 几乎无用**（贡献 0.0068）。统计显著（p=0.03）但经济意义可忽略。月频前向填充引入的低频信息不足以驱动日频相关性变动。

#### CB 触发期 vs 非触发期

| 因子 | CB触发期均值 | 非触发期均值 | 差值 | p |
|------|------|------|------|------|
| CN 10Y | 3.48 | 2.92 | **+0.56** | <0.001 |
| 10Y-2Y Spread | 0.43 | 0.46 | -0.03 | <0.001 |
| CPI YoY | 0.12 | 0.11 | +0.01 | 0.572 |
| US-CN Spread | -1.07 | -0.27 | **-0.80** | <0.001 |

熔断触发时 CN 10Y 显著更高（+0.56pp），US-CN 利差显著更负（-0.80pp）。这两个因子在熔断情景下有清晰的经济逻辑：高利率 + 资本外流压力 → 股债同跌 → 相关性转正。

#### 2022 年专项

2022 年是熔断最集中的年份（CB 触发 49.6% vs 全期 28.4%），但宏观因子的 z-score 偏离均 < 0.5σ：

**US-CN Spread 是 2022 年最异常的信号**：从全期均值 -0.49 翻转为 +0.20（美债收益率快速上行超过中债），驱动了更多 CB 触发天数。但即便如此偏离仅 0.49σ——2022 年的极端熔断并非宏观变量异常到史无前例，而是股债相关性在正常宏观范围内走到了临界值。

#### 对熔断机制的启示

1. **R² = 0.32 不高不低。** 宏观因子有一定解释力但不足以做精确预测。不能指望"看 CN 10Y 突破 X 就预警熔断"这种确定性规则。
2. **CN 10Y 是唯一有实际影响力的主导变量。** 利差和 CPI 的边际贡献可忽略。如果做宏观预警，只看 CN 10Y 就够了。但 CN 10Y 本身又是政策内生变量，难以提前预判。
3. **熔断捕捉的更多是微观结构而非宏观框架。** 32% 可解释，68% 来自其他——可能是市场情绪、流动性冲击、政策超预期、全球风险偏好等不可量化因素。这意味着用宏观框架替代或削弱熔断是危险的。
4. **2022 年并非宏观极端年。** 宏观因子仅偏离 0.5σ，但 CB 触发率翻倍（28%→50%）。熔断在正常的宏观范围内就高频触发了——说明它捕捉的是相关性本身的临界行为，不是宏观变量的极端值。
5. **结论：保留熔断，不用宏观替代。** 熔断机制捕获的信号是宏观框架解释不了的微观结构部分。宏观数据可作为辅助理解，但不应进入决策链。
