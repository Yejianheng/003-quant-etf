## 步骤 1：修复 T+1 现金泄漏

### 问题

`src/backtest_engine.py` line 162：`repo_cash = exec_alloc["repo_amount"]`。

T+1 模式下 `exec_alloc` 来自 T-1 日 alloc，`repo_amount` 基于 T-1 日 NAV 计算。T 日持仓涨跌后 NAV 已变，但 repo_cash 仍取旧值，导致 `NAV ≠ positions_value + repo_cash`，每天泄漏当日市值变动量。12 年累积把策略漏穿。

### 修复

```python
# 改前
repo_cash = exec_alloc["repo_amount"]

# 改后：残差计算，现金守恒
positions_value = sum(...)
repo_cash = nav - positions_value
```

同时修复首日 `pending_alloc=None` 导致空仓：`execution_lag=1` 首日直接执行当日 alloc。

### 验证

全量测试 225 passed / 0 regression（1 预存故障与本次无关）。

## 步骤 3：差异分析与决策

### 真实 Look-Ahead Bias：ΔSharpe ≈ 0.18

修复后仍有显著偏差。**根因不是信号使用了未来数据，而是信号含当日收盘价。**

执行流程：
- `execution_lag=0`：T 日收盘价 → 算信号 → T 日收盘价成交（**物理不可能**：同一瞬间既用于计算又用于成交）
- `execution_lag=1`：T 日收盘价 → 算信号 → T+1 日收盘价成交（**物理可行**：T 日盘后算信号，T+1 日以收盘价执行）

差值 0.18 就是「先知当日收盘价」给策略带来的优势。MA40 看似迟钝，但每日收盘价对趋势过滤（涨破/跌破 MA40）和二层的截面排名都有瞬间影响——当日确认突破即可当日成交，延迟一日则错过首日收益。

### 决策

ΔSharpe 0.176 ≥ 0.05，按 direction.md 需待顾问决策：

- **选项 A**：保持 `execution_lag=0`（默认）。已知偏差量级 0.18，策略 Sharpe 1.23 仍远优于基准。
- **选项 B**：切换 `execution_lag=1`（默认）。消除偏差，策略 Sharpe 降至 1.06（仍优于三基准），回撤仅恶化 0.5pp。
- **选项 C**：折中——默认 T+0 但文档标注偏差量级，回测报告附带 T+1 对照列。

> 备注：选项 B 的 1.06 仍显著优于沪深300/创业板/纳指的买入持有基准，策略并未失效。之前 0.02 是现金泄漏假象。
