## 当前任务：进攻层逻辑切换 — 截面动量 → 时间序列动量

### 背景

[进攻层失效分析.md](../../进攻层失效分析.md) 确认截面动量在 A 股行业 ETF 上不产生 alpha。根本原因不是候选池结构，是截面排名的核心假设（"比别人涨得多→继续涨"）在 A 股不成立。

### 修正方案

**放弃截面排名，改用时间序列动量——与防御层统一逻辑。**

#### 规则

```
for each ETF in 候选池:
    if price > MA(40):  → 通过
    else:               → 不通过

进攻仓位 = 所有通过的 ETF，等权分配
若无 ETF 通过 → 全部 repo
```

| | 旧（截面动量） | 新（时间序列动量） |
|------|------|------|
| 判断 | 跟别人比 | 跟自己比 |
| 熊市 | 必须选"跌最少" | 全不通过 → 空仓 |
| 候选数要求 | 20+ | 6 够用 |
| 仓位 | Top-K 等权 | 通过即等权 |

### 候选池

沿用现有 6 只行业 ETF：证券/科创芯片/有色/医疗/消费/电池。风险源分类暂不调整——先验证时间序列逻辑本身是否有效。
