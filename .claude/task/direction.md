## 当前任务：进攻层结构重构 — 主题 ETF 轮动 → 一级风险源轮动

### 背景

[进攻层失效分析.md](../../进攻层失效分析.md) 确认：纯进攻 Sharpe -0.15~0.23，独立不产生 alpha。根因不在参数，在候选池结构。

### 三个结构问题

1. **层级混乱**：一级风险源（消费）和二级主题（芯片、电池）混在同一池子里做截面排名——不可比
2. **高 Beta 主题污染**：芯片/电池天然高波动，z-score 后仍易形成短期收益极值，系统持续追逐短周期热点
3. **主题轮动持续性极差**：40 日 EWMA 确认时行情往往已结束

### 修正方案

#### 步骤 1：重构候选池——按一级经济风险源重新分类

新候选池（6 源 × 1 只代表性 ETF）：

| 风险源 | 候选 ETF（需验证 AUM/成交/上市年限） |
|--------|------|
| 消费 | 待筛选（排除酒/食品饮料等主题，选最纯的消费 ETF） |
| 金融 | 待筛选（证券/银行/保险中选择） |
| 科技 | 待筛选（宽基科技，非芯片/半导体/AI 主题） |
| 周期 | 待筛选（有色/化工/建材中选择） |
| 医药 | 待筛选 |
| 军工 | 待筛选 |

**禁止进入主轮动池**：芯片、电池、AI、机器人、算力等二级主题 ETF。

筛选标准（沿用）：AUM≥5亿 / 日均成交≥1000万 / 上市≥2年 / 同风险源去重留最大。

#### 步骤 2：进攻层增加绝对趋势过滤

规则：
```
if price > MA(40):
    进入截面排名
else:
    仓位 → repo/现金
```

与防御层统一逻辑——只在上升趋势中持有，熊市空仓。

#### 步骤 3：纯进攻隔离测试

跑 `defense_ratio=0.0` + 新候选池 + 趋势过滤 + K=2~6：

```
纯进攻 K=2 → 纯进攻 K=6
```

输出三基准对比表 + 与旧候选池同口径对比。

#### 步骤 4：混合回测

跑 `defense_ratio=0.70` + 新候选池 + 趋势过滤 + K=2~6，与旧混合配置对比。
