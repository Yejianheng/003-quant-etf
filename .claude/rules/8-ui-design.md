# UI 设计规范（前端项目）

## DESIGN.md 优先

涉及前端 UI 时，必须从 [awesome-design-md](https://github.com/Yejianheng/awesome-design-md) 选取一个 DESIGN.md 放入项目根目录（73 个品牌可选，如 ClickHouse / Linear / Airbnb）。

选定后 AI 自动按该色彩/字体/组件规范生成 UI，禁止脱离 DESIGN.md 自由发挥视觉风格。
