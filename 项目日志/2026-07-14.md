## 09:30 — execution_lag=1 修正审查：repo_cash 系统性负值

**现象**：v211 execution_lag=1 修正后，审查发现全量回测 3025 个交易日中 966 天（32%）`repo_cash < 0`，即 `positions_detail` 持仓市值之和 > NAV。图表 2026 年范围内 126 天中 40 天为负。

**排查路径**：
1. 图表逻辑验证 → 图表忠实呈现引擎输出，非图表问题
2. 引擎内部一致性 → `exposure == sum(positions_detail)` 逐日零偏差，NAV 计算自洽
3. 逐日手工验算 → 发现 Δ% 与手工预测偏差 0.5% 以上的有 477 天，初步怀疑换仓日 overnight gap
4. 分类统计 → 678 天非换仓日（前后信号完全相同）也负 repo，排除"换仓 gap"假说
5. 定位根因 → [backtest_engine.py:162-179](src/backtest_engine.py#L162) `total_at_open = old_value_open + repo_cash` 是动态值，但 [backtest_engine.py:220](src/backtest_engine.py#L220) `allocate_capital` 的 target 基于 `nav`（T-1 收盘静态值）。两者不一致时 `new_target_sum > total_at_open` → `repo_cash = total_at_open - new_target_sum - commission` 被挤成负

**根因**：direction.md 1c 指定用 `prev_nav` 做现金守恒上限，实现时改为动态 `total_at_open`。非换仓日即便 turnover 为零，`total_at_open` 与 `nav` 的微小偏差（来自 overnight gap + 累计浮点误差）经佣金放大后累积为负。换仓日 overnight gap 为负时负值放大。

**影响**：2026 年最严重三天 — 02-02（-144,116, -3.64%）、03-23（-81,774, -2.19%）、06-08（-92,631, -2.28%）。负 repo 等效于无成本杠杆，图表所有指标（NAV、Δ%、Sharpe、回撤）均带水分。

**待修**：direction.md 或直接修 `backtest_engine.py`，方案待用户定。
