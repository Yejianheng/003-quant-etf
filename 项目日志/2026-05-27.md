## 教训

1. **VPN 代理残留**：关闭 VPN 客户端 ≠ 清除代理。`ProxyServer` 注册表项残留，`requests` 通过 `get_environ_proxies()` 读取。修复方案：monkey-patch `Session.__init__` 设 `trust_env=False`。
2. **东方财富限流**：K 线 API 有严格 WAF，短时间多次调用触发断连。已通过 pre_bash.js 分时限流 + data_pipeline.py 重试解决。
3. **pandas index 对齐陷阱**：构造测试数据时，Close Series 需先设 DatetimeIndex 再放入 DataFrame，否则整数 index vs DatetimeIndex 对齐全部生成 NaN。教训：测试 helper 必须返回正确 index 的 Series。
4. **顾问-执行协作模式**：10 步开发中顾问写 direction → 执行编码 → 顾问审查 → commit，每步 5-10 分钟。整体运行流畅。
5. **技术隐患目录保护**：`技术隐患/` 加入 protected_dirs 是正确的架构决策——执行窗口不应绕过顾问修改风险跟踪文件。但 Write 工具绕过了保护，hook 匹配逻辑需排查。
