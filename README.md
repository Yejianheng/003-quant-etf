# 003-quant-etf

ETF 多资产动量轮动量化系统。动量因子驱动 ETF 轮动，AI 辅助纪律执行。

## 策略概要

**50/50 A/B 组合**：50% 无 sf + 50% sf+0.18，等效单策略 `combined_mult = (dd_mult + min(sf, dd_mult)) / 2`。低波动满仓、高波动折中，牛熊自动切换权重。

**六步决策链**：趋势过滤 → 等权分配 → EWMA 波动率缩放 → 股债相关性熔断 → 回撤硬止损 → 资金路由。

**资产池**：沪深300(510300)、创业板(159915)、纳指(513100)、黄金(518880)、国债ETF(511010)。
